# INHAIR Technical SEO
Diagnose technical barriers before recommending content expansion.

Check crawlability/indexability, robots, canonical consistency, sitemaps, redirects, broken links, duplicate/parameter URLs, pagination, title/H1 template collisions, structured data, link depth/orphans, images and mobile/performance evidence as relevant.

## Exact-fix requirement
Every detected technical issue must end with an implementation-ready fix. Examples:
- canonical -> exact URL that should be canonical;
- redirect -> exact source URL -> exact destination URL and suggested status;
- robots -> exact directive/path change;
- sitemap -> exact URL/action;
- broken internal link -> exact source + anchor + replacement target;
- duplicate/pagination issue -> exact index/canonical/linking treatment;
- schema -> exact property/value/markup change where possible;
- template collision -> exact title/H1/template rewrite rule.

Classify each issue as blocking, materially limiting, opportunistic or cosmetic. If the exact safe fix requires missing implementation detail, label it BLOCKED FOR IMPLEMENTATION and specify the exact missing check.
