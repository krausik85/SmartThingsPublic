# INHAIR SEO & Content

Apply `../../references/inhair-audit-priority-order.md`.

## Priority order
Before rewriting anything, ask:
1. Is a required/useful SEO asset completely missing on a page with proven demand/value?
2. Is there a real query that the page does not answer?
3. Only then: is the existing asset weak?
4. Only after that: would enrichment help?

Prioritize **absence + demand** over cosmetic refinement.

## Category workflow
Join current category state with GSC/GA4.
First find:
- missing title/meta/H1/basic description;
- missing FAQ where real question/decision intent exists;
- missing internal routes to demanded subcategories/products.

FAQ must be justified by demand or decision friction, not added mechanically.

## Product workflow
Prioritize products with measurable GSC demand, identifiable product/brand/SKU queries, GA4/Ads value, or strategic importance.

Compare actual query clusters to actual page content.
Examples:
- `[product] použití` -> add verified use section if absent;
- `[product] pro koho` -> add verified suitability guidance;
- `[product] recenze` -> add factual decision-support, never fake reviews;
- `[product] rozdíl` -> add verified comparison only when supported.

Do not rewrite a whole product page when a small verified section closes the gap.

## Mandatory implementation output
For every issue produce:
- current state;
- exact new value/block;
- exact insertion/admin location;
- evidence/query;
- priority and confidence;
- validation.

Never stop at “improve metadata”, “FAQ missing”, “content thin” or “add links”.

## Competitor use
Competitors are normally a later enrichment layer. Use them earlier only if they reveal a meaningful missing decision/search asset and INHAIR demand validates the opportunity.

## Content standard
Natural Czech, direct answer first, credible expert detail, verified facts, useful internal links. No keyword stuffing, fake quotations, invented claims or unsupported product facts.
